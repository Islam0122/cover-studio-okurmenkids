# Cover Studio

Онлайн-генератор обложек, титульных листов, сертификатов, отчётов и титульных слайдов формата A4 с живым редактором и экспортом в PDF/PNG.

**Стек:** React 19 · TypeScript · Vite · Tailwind CSS 4 · Zustand · Fabric.js 7 · jsPDF · Lucide React · React Router 7

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # production-сборка в dist/
npm run preview      # проверить сборку локально
npm run typecheck
```

## Деплой

- **Vercel / Netlify** — `npm run build`, папка `dist`. Переписывание маршрутов уже настроено (`vercel.json`, `public/_redirects`).
- **GitHub Pages и любой статический хостинг без rewrites** — `npm run build:static`: hash-роутинг (`/#/editor/...`) и относительные пути, работает из любой подпапки.

## Возможности

- Лендинг, каталог шаблонов (6 категорий, поиск по названию/тегам, фильтр по ориентации), страница «Мои проекты».
- 12 шаблонов: университет (2), школа (2), IT-проекты (2), сертификаты (4, включая фирменные «Окурмэн Kids» и «Best Student of the Month»), отчёт, презентация.
- Встроенный логотип Окурмэн Kids (кнопка «Готовые» у поля логотипа) и поле «Печать / подпись»: у загруженного фото печати фон бумаги удаляется автоматически.
- Редактор в три колонки:
  - **слева** — данные (работа, автор, руководитель, учреждение, логотип, изображение), выбор шаблона и ориентации, цвета темы, пресеты, шрифты, фон (цвет / градиент / фото);
  - **центр** — холст Fabric.js в точных пропорциях A4: выделение, перетаскивание, масштабирование, поворот, редактирование текста двойным кликом, зум (кнопки, Ctrl+колесо, «вписать»), режим просмотра;
  - **справа** — свойства элемента (X/Y/Ш/В, угол, прозрачность, шрифт, размер, насыщенность, выравнивание, интервалы, цвет, заливка, обводка, скругление) и слои (порядок, видимость, блокировка).
- Добавление своих элементов: текст, прямоугольник, эллипс, линия, изображение; дублирование, удаление, undo/redo.
- Экспорт PNG и PDF, A4 книжная/альбомная, 192 / 300 / 384 DPI.
- Фирменный набор: логотип, печать и подпись запоминаются в браузере и подставляются во все новые проекты. Подпись можно нарисовать на экране (мышь, палец, стилус) или загрузить скан.
- Загруженные изображения хранятся один раз (`store/assetStore.ts`, WebP), проекты ссылаются на них как `asset:<id>`; неиспользуемые удаляются автоматически.
- Автосохранение проектов в LocalStorage (загруженные картинки ужимаются, переполнение хранилища показывается баннером).

## Архитектура

```
src/
  types/template.ts        модель документа: элементы, палитра, шрифты, поля
  templates/               определения шаблонов (параметрические layout(W, H)), сборка документа
  store/editorStore.ts     открытый документ, выделение, история, зум, превью
  store/projectStore.ts    проекты (persist → LocalStorage)
  utils/renderer.ts        единый рендерер Fabric: холст редактора, миниатюры и экспорт
  utils/exportImage.ts     PNG
  utils/exportPdf.ts       PDF (jsPDF, загружается лениво)
  components/editor|forms|templates|projects|layout|ui
  pages/                   Home, Templates, Projects, Editor
```

Ключевые идеи:

- **Один рендерер.** Миниатюры в галерее, холст редактора и экспорт рисуются одним кодом, поэтому скачанный файл совпадает с тем, что видно на экране.
- **Поля и токены.** Текст хранит плейсхолдеры `{{studentName}}`, цвета — токены `$primary`, шрифты — `$heading`/`$body`. Форма слева меняет поля, палитра перекрашивает всё сразу, а смена шаблона сохраняет введённые данные.
- **Параметрические шаблоны.** Каждый шаблон — функция от размеров листа, поэтому переключение книжная ↔ альбомная перестраивает макет, а не растягивает его.
- **Инкрементальная синхронизация.** Холст пересоздаёт только изменившиеся объекты (по хэшу элемента), не теряя выделения.

### Добавить шаблон

Добавьте `TemplateDefinition` в `src/templates/index.ts` и включите его в массив `TEMPLATES`. Используйте фабрики `text()`, `shape()`, `image()` из `utils/document.ts`.

## Заметки

- PDF содержит растровую страницу 300+ DPI: так кириллица и все Google-шрифты выглядят одинаково без встраивания TTF в jsPDF.
- `html-to-image` не используется: Fabric сам отдаёт холст в нужном разрешении, отдельный DOM-снимок не нужен.
